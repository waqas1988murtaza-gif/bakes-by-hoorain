# Bakes by Hoorain 🎂

Streamlit website for **Bakes by Hoorain** — a home-based customized cake business in Karachi.

- Photo gallery of cakes & desserts
- Full price menu in PKR
- WhatsApp ordering (0312 7904882) — every item opens WhatsApp with a ready order message
- TikTok / Instagram / Facebook links

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy free on Streamlit Community Cloud

1. Open https://share.streamlit.io → **New app**
2. Select this repository (`bakes-by-hoorain`), branch `main`, file `app.py`
3. Click **Deploy** — the site goes live at `bakes-by-hoorain.streamlit.app`
